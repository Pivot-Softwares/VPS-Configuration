## Goal

The OVH VPS is rebuilt and secured, and the three applications are deployed to it through GitHub Actions, with no
personal access token anywhere.

## Acceptance criteria

1. The VPS answers from outside only on HTTPS and key-only SSH, installs its security updates automatically, and
   meets the baseline of the `vps-hardening` skill, each item recorded in a decision record with how it was done.
2. RaidManager runs dev, test and production; Delivery Atlas and the Pivot Softwares website run production; each
   deploys from GitHub without anyone signing in to the server.
3. Uptime, certificates, disk and backups are monitored for free, an alert reaches the owner in a test, and a restore
   test succeeds.
4. No personal access token remains in use on GitHub, Azure DevOps, the server or the owner's PC; every remaining
   credential is registered and flagged (`credentials-policy`).
5. Every DNS record of `pivotsoftwares.com` is registered and checked from outside, and Zoho mail works.

The repository's quality gates pass on the released configuration, and the stabilization sprint records its release
checks below.
