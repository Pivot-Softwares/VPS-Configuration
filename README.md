# VPS-Configuration

Security, configuration and deployment of the Pivot Softwares OVH VPS, which hosts the applications under
`pivotsoftwares.com`: RaidManager, Delivery Atlas and the Pivot Softwares website.

## Status

Planning. The VPS is being reset and rebuilt from this repository; see
[ADR-0001](docs/adr/0001-adopt-the-raidmanager-work-process.md) for the decisions so far.

## Contributing

Work follows the RaidManager process: every change is a task in the organization Project, delivered through one
branch and one draft pull request, reviewed by the owner and a peer. Agent instructions are in [AGENTS.md](AGENTS.md).
